**Framework**
===========

- 게임 엔진: Godot 4
- 개발 언어: GDScript, C#
- 3D 모델링: Blender
- AI 3D 에셋 생성: Meshy
- 2D 에셋 제작: AI 이미지 생성 도구로 텍스처, 포스터, UI, 아이콘 제작
- 제작 방식: AI로 초안을 생성하고 필요에 따라 Blender에서 수정
- 게임 적용: 3D 모델은 GLB, 2D 이미지는 PNG로 가져와 Godot에 적용

# 게임플레이 형식 정리

## 1. 기본 플레이

**집 안에서 생활을 유지하며, 바깥의 상황을 관찰해 범인이 검거될 때까지 살아남는 1인칭 공포·추리 생존 게임.**  
주인공은 빌라에 혼자 사는 재택 프리랜서 개발자다. 밤마다 찾아오는 범인 때문에 제대로 쉬지 못하지만, 생활을 유지하기 위해 일을 하고 물품을 받아야 한다.  
플레이어는 **3D 1인칭 시점으로 집 안을 돌아다니며 특정 사물과 상호작용**한다. 시간은 업무·식사·취침·외출·인터폰 응답 등 특정 행동을 통해 흐른다.  
핵심 경험은 **집에서도 안전하다고 느끼지 못하는 불안감, 휴식하지 못해 쌓이는 피폐함, 그럼에도 생활을 이어가야 하는 압박감**이다.

## 2. 주요 상호작용

| 행동 | 주요 기능 |
| ------------ | ---------------------------------- |
| 인터폰 확인 | 방문자와 복도 상황을 관찰하고 대화하거나 없는 척한다. |
| 현관 렌즈 확인 | 인터폰과 다른 시야로 현관 밖을 확인한다. |
| 창밖 확인 | 건물 밖의 상황과 흔적을 관찰한다. |
| 지역뉴스 확인 | 주변 사건과 관련 정보를 얻는다. |
| 휴대폰 사용 | 음식·식료품·조사 물품·호신용품을 주문한다. |
| 식사 | 공복을 해결하고, 음식 종류에 따라 정신력도 회복한다. |
| 취침 | 시간을 보내며 정신력을 회복한다. |
| 업무 | 미리 정한 시간 동안 일하고 돈을 번다. |
| 산책 | 외출하여 정신력을 관리한다. |

인터폰·현관 렌즈·창밖은 **정지 화면**으로 표현한다. 시간이 지난 뒤 다시 확인하면 사람의 위치나 주변 환경이 달라질 수 있다.  
산책과 외출의 구체적인 표현 방식은 미정이다.

## 3. 시간과 생활 일정

플레이어는 식사·수면·업무·배송 회수를 고려해 하루의 일정을 조정한다.  
**업무:** 시작 전에 한 번에 몇 시간을 일할지 정한다. 오래 연속해서 일할수록 능률이 오르지만, 다른 활동에 사용할 여유가 줄어든다. 업무는 유일한 수입원이다.  
**수면:** 원하는 때에 침대에 누울 수 있다. 다만 전날과 크게 다른 시간에 자면 수면 시간이 줄고 정신력 회복도 낮아진다. 방문자의 초인종으로 잠에서 깰 수 있다.  
**밤낮 전환:** 범인의 야간 방문을 피하려고 낮에 자는 전략도 가능하다. 대신 대부분 낮에 오는 배송을 놓칠 수 있고, 밤 산책의 정신력 회복 효과는 낮다.  
따라서 한 가지 생활 방식에 고정되기보다 필요한 물품과 현재 상태에 맞춰 일정을 바꾸게 된다.

## 4. 공복과 정신력

**공복**  
조리도구를 사용하지 않는 주인공은 배달음식과 배송받은 간편식품으로 식사한다. 컵라면이나 통조림을 비축하면 문을 여는 횟수를 줄일 수 있다.  
**정신력**  
충분히 자지 못하거나 오랫동안 외출하지 않으면 정신력이 감소한다.  
간편식은 공복을 해결하지만 정신력 회복 효과가 낮다. 맛있거나 좋아하는 음식을 주문하면 정신력 회복에도 도움이 되지만, 문을 열어 음식을 회수해야 한다.  
정신력이 일정 수준 이하로 내려가면 주인공은 두려움 때문에 밤 외출을 거부한다. 더 심한 저하 상태에서는 초인종소리 변화·시야 흐림·텍스트 깨짐·게임오버 등을 구상하고 있다.

## 5. 방문과 물품 회수

초인종이 울리면 플레이어는 인터폰으로 방문자를 확인한다. 방문자는 배달부·이웃·범인 등이며, 아무도 보이지 않는 화면이 나올 수도 있다.  
화면과 함께 상황에 맞는 선택지가 나온다.

- 상대에게 응답하거나 방문 목적을 묻는다.
- 없는 척하며 기다린다.
- 다른 관찰 수단으로 확인한다.
- 문을 열고 물품을 받는다.

없는 척하더라도 방문자가 다시 호출할 수 있다. 시간이 지난 뒤의 화면에서는 방문자가 사라지거나, 물건의 위치와 복도 상태가 바뀔 수 있다.  
플레이어는 **주문 정보·대화·소리·주변 환경의 변화**를 연결해 문을 열어도 되는지 판단한다. 초인종이 울리지 않았을 때도 바깥을 확인할 수 있다.  
배송된 물품을 오래 회수하지 않으면 도난당할 수 있다. 따라서 안전을 확인하며 기다리는 것과 필요한 물건을 확보하는 것 사이에서 선택해야 한다.

## 6. 조우와 방어

범인과 마주치면 기본적으로 게임오버다.  
미리 구매한 호신용품이 있다면 한 번 방어할 수 있다. 하지만 범인은 사용된 수단에 대비하므로 같은 방법은 이후 통하지 않는다. 플레이어는 범인의 대사를 통해 이를 유추할 수 있다.  
다시 방어하려면 다른 호신용품이 필요하며, 이후 물품은 점점 비싸지는 방식을 구상하고 있다.

## 7. 목표와 진행 경로

**기본 생존 경로**  
공복과 정신력을 관리하고, 필요한 수입과 물품을 확보하며 경찰이 범인을 검거할 때까지 버틴다. 증거를 수집해 전달하면 검거까지 걸리는 시간을 단축하는 방향이다.  
기본 흐름은 다음과 같다.  
**현재 상태 확인 → 생활 일정과 구매 계획 → 업무·식사·휴식 → 방문 발생 → 바깥 관찰과 대응 → 물품·증거 확보 → 생존 지속**  
**추가로 구상한 분기**  
중간에 직접 대응하는 사적 제재 경로를 선택할 수도 있다. 이 경우 구매와 조사의 목적이 최종 대결 준비로 달라진다. 세부 진행은 미정이다.  
**아직 결정하지 않은 주요 규칙**  
업무 중 방문이 발생했을 때의 처리, 업무 중단 손실, 수면 방해의 빈도, 게이지 수치와 실패 기준, 산책의 구체적인 진행 방식은 추후 정한다.
