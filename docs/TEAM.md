# 팀 작업 시작점

현재 단계에서는 숫자를 확정하기보다 한 번 플레이한 뒤 감상을 비교합니다.

- 기획/통합 1명: 테스트 진행, 사건·대사·일정 조정, Godot 통합
- 프로그래밍 1~2명: `state.gd`의 규칙과 `main.gd`의 플레이어·UI를 분리해 확장
- 환경 1명: Blender로 작은 방/현관 제작, GLB 적용. 현재 방의 1단위는 약 1m
- 시각·음향 1명: 인터폰/렌즈/창밖의 같은 사건별 정지 화면, UI, 문·발소리
- 여유 인원 1명: 플레이테스트와 사건 제작 지원

첫 피드백은 세 질문으로 모읍니다.

1. 정상 배달과 수상한 방문의 차이를 스스로 이해했는가?
2. 초인종 때문에 행동을 중단하는 선택이 긴장됐는가?
3. 증거 신고가 생존 시간을 줄여준다는 것을 이해했는가?

외부 에셋 적용 전에 `main.gd`의 절차적 방 생성을 별도 `Room.tscn`으로 교체하고 UI를 장면으로 분리하는 것이 다음 구조 개선입니다. 규칙 테스트는 유지하세요. 현재 코드 생성 방식은 작은 시제품을 실행하기 위한 것입니다.
