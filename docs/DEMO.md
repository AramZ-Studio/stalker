# 시연 경로 두 개

`플레이.cmd` → 시작 화면에서 **사망 시연** 또는 **생존 시연**을 선택합니다.

각 화면의 **다음** 버튼으로 진행합니다. **자동 시연**을 켜면 5초마다 다음 단계로 진행합니다. Esc로 멈추거나 다른 경로로 바꿀 수 있습니다. 시연 종료 후 시작 화면에서 자유 플레이도 가능합니다.

이 시연은 실제 `state.gd` 규칙을 사용합니다. 생존 수치 강제 보정이나 엔딩 강제 호출을 하지 않습니다. 선택한 경로의 행동을 순서대로 실행하고, 그 결과를 보여줍니다. 이동 카메라는 각 행동 위치로 자동 이동합니다.

## 사망 — 주문하지 않은 방문 (4단계)

1. 저녁 6시, 주문 없이 업무 시작
2. 4시간 업무 후 밤 10시 방문. 배달을 자칭하지만 주문 내역은 없음
3. 번호를 물어도 답하지 않고 문을 열라고 재촉. 맨손과 모자가 관찰됨
4. 문 열기 → 실제 범인 조우 판정 → 사망

## 생존 — 관찰과 신고 (14단계)

1. 18:00 간편식 주문 (0417)
2. 업무 중 19:00 배송으로 중단. 주문 번호와 물품 확인
3. 정상 물품 회수 후 업무 재개, 20:00 종료
4. 추가 업무 중 22:00 범인 방문으로 중단
5. 현관 렌즈에서 손목 문신 기록, 문을 열지 않음
6. 업무 중단 후 한 시간 대기, 23:00 범인 퇴장
7. 창밖 차량 번호 7319 기록
8. 증거 두 개 신고, 검거 시각 12시간 단축
9. 식사 후 23:30
10. 8시간 수면 후 다음 날 07:30
11. 4시간 업무 후 11:30
12. 식사 후 12:00
13. 4시간 업무 후 16:00
14. 2시간 대기, 18:00 검거 → 생존

수동 시연은 설명 속도에 맞춰 진행할 수 있습니다. 자동 시연은 사망 약 15초, 생존 약 65초이며 단계마다 언제든 멈출 수 있습니다.

검증: `--headless --path . -- --test-demos` 명령은 두 경로를 모두 끝까지 실행하고 시간·신고 수·엔딩을 검사합니다.
