# 기획서 기준 기능 점검

기본 플레이는 **자유 시연 · 생활과 문밖**입니다. 현관 연출을 시험하는 짧은 모드는 보조 메뉴이며 본 게임의 목표를 대신하지 않습니다.

## 확정된 핵심과 현재 연결 상태

| 기획 내용 | 통합 자유 시연 구현 |
| --- | --- |
| 집 안 3D 1인칭 이동·사물 상호작용 | PC·침대·식료품·휴대폰·현관·인터폰·창 |
| 재택 개발자의 생활과 생존 | 실제 일한 시간의 수입으로 구매, 공복·정신력 유지, 검거까지 생존 |
| 인터폰·렌즈·창밖의 정지 화면 | 다른 시야·문 옆 사각지대·재확인과 시간 경과에 따른 변화 |
| 뉴스·주문·대화·소리 비교 | 휴대폰 지역 뉴스·품목·송장 번호·대화·공간 소리와 자막 |
| 필요한 물품과 위험한 방문의 혼동 | 동일한 후드·상자·번호를 사용하는 사칭, 서로 다른 물품 답변·머무르는 소리 |
| 행동으로 흐르는 시간 | 업무·수면·식사·대기·외출. 관찰·메뉴·실내 이동은 시간 소비 없음 |
| 업무 시간 사전 선택·연속 능률·유일한 수입 | 1·2·4시간 선택, 실제 일한 시간과 연속 시간에 따른 수입 |
| 자유로운 수면·수면 일정 변화 페널티 | 2·4·8시간, 취침 시각 차이 4시간 초과 시 수면 길이와 회복 감소 |
| 초인종 수면 방해·업무 중단 | 방문 시 정지, 남은 행동 재개 또는 중단. 반복 노크도 방해 가능 |
| 낮잠 전략과 낮 배송의 충돌 | 보통 물품은 낮 시간 도착. 낮잠을 계속하면 회수가 늦어져 물품 분실 가능 |
| 비축식·좋아하는 음식 | 간편식 재고와 좋아하는 음식 분리. 공복 감소·정신력 회복량 차이 |
| 조리 없이 배송·배달로 식사 | 식품도 실제 배송 후 문을 열어 회수해야 사용 가능 |
| 수면·외출 부족에 따른 정신력 저하 | 장시간 각성·오랫동안 외출하지 않으면 추가 저하 |
| 낮·밤 산책 효과 차이 | 낮 회복 18 / 밤 5. 정신력 35 미만이면 밤 외출 거부 |
| 심한 정신력 저하와 실패 | 저하 시 심장박동(반복 FOV 변화 제거), 정신력 0 또는 공복 100이면 실패 |
| 배달부·이웃·범인·빈 화면 | 정상 배송, 이웃의 우편물 방문, 사칭과 사각지대, 떠난 뒤의 복도 |
| 응답·없는 척·재확인·문 열기 | 목적 질문·귀 기울이기·15/30분 대기·다른 시야·문 열기 유지 버튼 |
| 미회수 배송 도난 | 도착 후 3시간 미회수 시 분실. 비용은 반환되지 않음 |
| 조우 시 기본 실패·1회 방어 | 보유한 호신 수단 한 개를 소비해 생존, 정신력 손실 |
| 같은 수단은 다시 불통·다른 수단 필요 | 스프레이·경보기·손전등, 사용한 종류 재구매 불가·범인 대사 변화 |
| 이후 방어 물품 가격 상승 | 사용한 수단 수에 따라 다음 호신용품 가격 증가 |
| 조사 물품 구매 | 현관 기록 카메라를 배송·회수한 뒤 설치 상태로 사용 |
| 증거 수집·전달로 검거 단축 | 문신·차량·설치 이후 녹화의 새 증거마다 6시간 단축 |
| 현재 상태→생활 계획→방문 판단→확보→생존 | 같은 상태·시간·재고·주문·종료 조건으로 연결. 별도 미니게임 목표로 대체하지 않음 |

## 시제품에서 정한 임시 수치

- 기본 검거는 4일차 06시. 증거 세 개를 모두 제보하면 18시간 단축됩니다.
- 시작은 1일차 18시, 간편식 1개, 42,000원, 공복 32, 정신력 78입니다.
- 음식은 약 45분 배송, 일반 물품은 낮 배송입니다. 동시에 진행하는 주문은 한 건입니다.
- 업무 중단 전 수입·회복은 유지됩니다. 새 행동을 시작하면 이전 잔여 행동은 취소됩니다.
- 스토커의 야간 방문 시각은 매 플레이 달라지며, 숨은 정체를 UI에 바로 표시하지 않습니다.
- 산책은 선택과 결과로 표현하며, 자유로운 실외 이동은 없습니다.

## 원래 기획에서 미정이었던 확장

**사적 제재 경로·최종 대결**은 원 기획에서도 세부 진행이 미정인 추가 분기입니다. 이 구상은 유지하되 현재 실행 가능한 엔딩은 기본 생존·검거 경로와 실패 경로입니다. 구현 완료로 표시하지 않습니다.

수면 방해 빈도·정확한 밸런스·외출의 3D 표현·심한 정신력 저하의 텍스트 깨짐은 추가 설계·연출 항목입니다. 이번 임시 규칙을 확정 기획으로 취급하지 않습니다.

## 검증

`test_full_game.gd`는 업무·수면·식사·낮 배송·물품 회수·다른 방어 수단·조사 카메라·증거 신고를 하나의 실제 시간선에서 연결해 검거 엔딩까지 확인합니다. `--test-full-ui`는 모든 생활 사물과 새 현관 관찰 UI의 연결, 문 열기 유지, 방어·사망 화면을 검사합니다.
