# 문밖의 배달 — 현관 중심 공포 플레이

## 이번 개선의 목표

‘방문자의 모델을 보고 정답을 고르는 시연’에서 ‘확인한 정보들을 비교하고 문을 열지 판단하는 짧은 플레이’로 전환합니다. 생활 시스템을 모두 확장하는 대신 현관 앞에서의 불확실성과 망설임에 집중합니다.

## 플레이

시작 화면의 **자유 시연 · 문밖의 배달**을 선택합니다. 실내를 자유롭게 돌아다니며 현관에서 E를 누릅니다. 방 안에서도 시간이 흐르고, 화면을 보는 동안에도 방문 상태가 바뀝니다. Esc로 일시정지할 수 있습니다.

야간 주문 3건에 수상한 방문 2건이 섞입니다. 생필품 2묶음 이상을 회수하고 모든 방문이 지나 아침이 되면 생존합니다. 정상 배송을 전부 놓치면 살아 있어도 목표를 달성하지 못합니다. 전체 소요 시간은 판단 속도에 따라 약 4–6분입니다.

### 단서와 불확실성

- 모든 방문자는 같은 무료 인물 모델·어두운 옷·상자를 사용합니다. 밝은 조끼와 모자만으로 구별할 수 없습니다.
- 주문 번호를 아는 사칭자도 있습니다. 실제 주문 물품과 답변 내용, 대면 수령 요구를 비교합니다.
- 정상 배달원이 짜증 섞인 목소리로 답하는 경우도 있습니다. 말투만으로 판단할 수 없습니다.
- 인터폰에는 문 바로 옆이 보이지 않습니다. 사람이 사라져도 렌즈 측면이나 남은 소리를 확인해야 합니다.
- 관찰 화면은 확인 순간의 정지 장면입니다. 신호·자막·공간음은 계속 들립니다. 다시 확인해야 위치 변화가 반영됩니다.
- 신원이 UI에 직접 표시되지 않습니다. 생존·사망 결과는 실제 물품·방문 상태로 계산합니다.

### 압박과 연출

- 첫 호출 전에 잠깐 기다리며 방 안을 익힐 수 있습니다.
- 정상 배송도 일정 시간이 지나면 사라지므로 무조건 기다리는 전략은 실패합니다.
- 문 열기를 1.2초간 유지해야 합니다. 중간에 손을 떼면 잠금 해제가 취소됩니다.
- 형광등 험, 실내 잡음, 현관 방향의 초인종·노크·옷깃·멀어지는 발소리, 관찰 중 심장박동을 합성해 사용합니다.
- 낮은 해상도·스캔라인·모서리 음영·전환 잡음과 어두운 복도를 사용합니다.
- 생필품 회수 시 문이 짧게 열렸다 닫힙니다. 위험할 때 열면 근접 조우 화면 뒤 실패 결과로 이어집니다.
- M 음소거를 지원하고, 판단에 필요한 소리 단서는 모두 자막으로 제공합니다.

## 아직 간소화한 범위

- 실시간 모드는 기존 생활 시스템과 별도입니다. 업무·공복·증거 신고를 추가로 요구하지 않습니다.
- 인물의 이동은 정지 화면을 새로 확인할 때 반영됩니다. 자유로운 실시간 추격 AI는 없습니다.
- 대사는 텍스트이며 음성 연기는 없습니다. 그래픽은 기존 Kenney CC0 에셋을 계속 사용합니다.
- 배송 순서가 바뀌며 사례의 세부 규칙은 정해져 있습니다. 실제 난이도·공포감은 사람의 플레이테스트가 필요합니다.
- 게임 내 시각은 방문 단계에 맞춘 연출 시각이며, 실제 플레이 시간과 일대일 대응하지 않습니다.
