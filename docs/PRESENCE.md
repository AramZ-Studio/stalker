# 플레이어 동작과 화면 몰입

적용 대상은 기본 통합 생존과 첫날 밤 모드입니다. 기존 안내·현관 전용 테스트는 별도 시연으로 유지합니다.

## 화면을 가리는 선택창 축소

현관에서 중앙 패널과 전면 어두운 배경을 제거했습니다. 인터폰은 별도 3D 정지 장면을 실제 기기의 화면 재질로 전달합니다. 렌즈는 얼굴을 가까이 가져가는 이동 후 원형 시야를 사용하고, 듣기는 카메라 영상을 닫고 실제 문 쪽으로 몸을 기울입니다. 창밖도 실제 창 표면에 별도 장면을 표시합니다.

선택지는 왼쪽 아래 작은 영역에 표시합니다. 기본 관찰 조작창은 1280×800 기준 화면의 10% 미만이며 대화 선택지도 아래에 배치합니다. 상황과 대답은 오른쪽 아래 자막입니다. 관찰 영상과 대화 선택지가 같은 화면에 남아 있어 설명창을 닫고 다시 확인할 필요가 없습니다.

1 인터폰, 2 렌즈, 3 듣기, 4 대화, E 길게 문 열기, R 기록, T 3분 기다리기, X/Esc 물러나기, Tab 휴대폰, G 산책. 대화 중 1–4는 질문 선택입니다. 창밖에서는 기록·휴대폰·물러나기만 허용해 현관으로 시점이 갑자기 옮겨가지 않게 했습니다.

공복·정신력·잔액·재고와 오늘 식사 여부는 오른쪽 위의 작은 반투명 상태창에서 확인하고, 휴대폰에서 상세 주문과 기록을 봅니다. 큰 상시 HUD와 기록 배너는 숨겼습니다. 업무·수면·식사 선택은 작은 하단 창으로, 휴대폰·기록·주문 안내는 오른쪽 폭 400px 패널로 표시하며 배경을 어둡게 하지 않습니다. 시작·일시정지·설정·엔딩은 기존 중앙 메뉴를 유지합니다.

## 동작과 애니메이션

- 즉각적인 마우스 시선 입력을 유지하면서 손에는 짧은 관성을 줍니다. 걷기에는 작은 수직 발 디딤·좌우 기울임, 정지 중에는 작은 호흡 움직임을 적용합니다. 오른쪽 마우스를 누르면 시야각을 조금 줄여 집중합니다. 보행 카메라 설정을 끄면 장식적인 흔들림과 기울임을 억제합니다.
- 두 손과 소매, 손가락 관절을 코드로 구성했습니다. 인터폰 버튼·현관 손잡이·키보드의 실제 위치를 기준으로 손이 향합니다. 버튼 누르기, 문에 손 대기, 물건 들기, 타이핑에 서로 다른 자세와 손가락 움직임을 사용합니다.
- 관찰에 들어가고 물러날 때 카메라를 약 0.3–0.4초에 걸쳐 이동합니다. 플레이어 본체를 다른 장소로 순간 이동시키지 않습니다. 관찰·대화·문 동작 동안은 걷기를 막습니다.
- E를 유지하면 먼저 기기나 렌즈에서 실제 문으로 시선을 옮기고 손을 뻗습니다. 잠금쇠를 돌린 뒤 손잡이가 내려갑니다. 1.2초 전에 놓거나 다른 화면으로 전환하면 열기 판정 없이 손·잠금쇠·손잡이가 복귀합니다.
- 안전하게 열면 한 걸음 물러난 시점에서 문짝이 열렸다 닫힙니다. 결과는 이후 자막으로 표시합니다. 기존 벽을 실제 현관 개구부로 바꾸고 짧은 문밖 공간을 추가했습니다.
- 범인을 만났을 때는 기존의 큰 조우 설명창 대신 문짝이 더 크게 밀리고 상대가 걷는 동작으로 다가옵니다. 상대의 팔다리와 고개도 움직이며, 이후 암전과 실패 메뉴로 이어집니다. 사망·방어·회수 판정은 기존 상태 규칙을 사용합니다.
- 업무는 앉는 높이로 시선을 낮추고 손가락을 움직입니다. 수면은 시점 낮추기와 눈 감기, 식사는 물건을 입 쪽으로 가져오는 동작을 사용합니다. 짧은 생활 연출은 Space/Esc로 건너뛸 수 있습니다.

캐릭터와 손은 정식 리깅 에셋이 아닌 절차적 시제품입니다. 움직임의 목적·타이밍·공간 위치를 검증하기 위한 구현이며 사실적인 피부·옷 주름·손목 IK·녹음 음성은 포함하지 않습니다.

## 시간과 검증

표현 계층은 `scripts/presence.gd`에 분리했습니다. 카메라·손·문 애니메이션은 실제 초 단위로 재생되지만 생활 시간, 공복, 배송과 방문 일정은 기존처럼 명시적 행동으로만 흐릅니다. 관찰 장면은 관절 계층의 위치가 렌더러에 반영된 뒤 한 번 렌더링해 고정합니다. 애니메이션 때문에 단서나 정체를 무작위로 바꾸지 않습니다.

`--test-presence`는 중앙 패널 제거, 조작창 면적, 기기 화면 연결, 관찰 중 시간 정지, 키보드 질문, 열기 취소와 손잡이 복귀, 손과 손잡이의 거리, 실제 문 개폐, 휴대폰 위치, 생활 동작과 조우 움직임을 검증합니다. 실제 OpenGL 렌더러에서도 실행하고 `--capture-presence`로 실내·인터폰·대화·잠금 해제·열린 문·렌즈·듣기·휴대폰·업무·조우 화면을 확인합니다. 미리보기는 `presence_*.png`입니다.
