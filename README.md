# OPEN UP · 문열어 — Godot 데모

## 게임 시작과 상황 체험실

시작 메뉴는 **게임 시작 · 일주일 생존 / 상황 체험실 / 설정 / 종료** 네 항목입니다. 플레이용 데모는 일주일 생존 하나이며, 이전 시연 버튼은 표시하지 않습니다.

데모에는 정상 방문을 익히는 초반부터 사칭·사각지대·배송 지연·대답을 흉내 내는 방문자·마지막 밤의 재방문까지 날짜별 변화가 있습니다. 일반 식량 배송은 **2끼 10,000원**, 시작 생활비는 **24,000원**입니다. 음식·조사 카메라·호신용품의 우선순위를 정하고, 주어진 일정을 바꾸며 필요한 것을 확보합니다. 제보·방어·놓친 배송은 생존 결말에 반영됩니다.

상황 체험실에서는 **38개 상황**을 방문·생활·조사·방어·결말로 나누어 선택하고 날짜·시간대·정신력·주문·식량·호신용품 조건을 변경합니다. **N 상황 진행 / F5 다시 체험 / F6 조건 변경 / F7 목록**을 지원합니다. 결과 화면에도 다시 체험·조건 변경·목록 버튼이 있습니다. 각 체험은 데모와 분리된 새 상태에서 실제 게임 규칙으로 판정합니다. 자세한 구성과 검증은 [docs/SCENARIO_LAB.md](docs/SCENARIO_LAB.md)에 있습니다. 아래 과거 변경 기록보다 이 절의 현재 메뉴·밸런스가 우선합니다.

## 현재 기본 규칙: 일주일 생존

시작 메뉴의 **일주일 생존 · 매일 한 끼**를 선택합니다. 1일차 00:00부터 7일차 24:00까지 168게임 시간을 버팁니다. **매일 최소 한 끼**를 먹어야 하며, 한 끼도 먹지 않은 채 자정을 넘으면 실패합니다. 전날 여러 끼를 먹어도 다음 날의 식사를 대신하지 못합니다. 오늘 식사 여부는 Tab 휴대폰과 식료품 메뉴에서 확인합니다. 증거 제보는 목표 기간을 줄이지 않고 이후 범인의 체류 시간을 줄입니다.

조작은 **WASD 기본 걷기 / Shift 달리기 / Ctrl 천천히 걷기**입니다. 둘을 함께 누르면 Ctrl이 우선합니다. 이동 속도와 보폭에 맞춰 좌우 발의 뒤꿈치·발끝·마찰음을 생성합니다. 달리기는 빠르고 크게, 천천히 걷기는 느리고 작게 들립니다. 정지·관찰·메뉴에서는 발소리가 나지 않습니다.

일주일 전체 생활 진행과 자정 식사 판정은 `tests/test_week.gd`, 키 조합·속도·보폭·좌우 발소리는 `--test-movement`로 검증합니다. **이 절이 현재 기본 모드의 규칙이며 아래 내용 중 짧은 첫날 밤·검거 단축은 이전 테스트 모드의 기록입니다.** 상세 변경은 [docs/WEEK_SURVIVAL.md](docs/WEEK_SURVIVAL.md)에 있습니다.

## 플레이어 동작과 화면 몰입 개선

통합 생존 모드와 첫날 밤 모드의 관찰·대화는 중앙 선택창을 사용하지 않습니다. 인터폰 영상은 집 안의 실제 기기 화면에 표시하고, 렌즈를 볼 때만 눈을 가까이 댄 원형 시야로 전환합니다. 선택지는 하단에 작게 표시하며 1–4, E 길게, R 기록, T 기다리기, X 물러나기로도 조작합니다.

손과 손가락, 기기에 손 뻗기, 렌즈에 다가가기, 문에 귀 대기, 잠금쇠·손잡이 조작, 문 열고 닫기, 타이핑·식사·눈 감기 애니메이션을 추가했습니다. 일상 이동에는 작은 호흡·시선에 따른 손의 관성·발 디딤을 적용하고, 오른쪽 마우스로 잠시 집중할 수 있습니다. 움직임 설정을 끄면 보행·호흡·기울임 효과를 억제합니다.

생활 상태는 Tab 휴대폰에서 확인합니다. 휴대폰은 오른쪽 패널, 일·수면·식사 선택은 하단 작은 패널로 열립니다. 행동 결과는 짧은 자막으로 표시합니다. 실제 문 뒤에 공간을 만들었으며 조우 시 문이 밀리고 상대가 안으로 움직이는 연출을 추가했습니다. 상세 규칙과 검증은 [docs/PRESENCE.md](docs/PRESENCE.md)를 참고하세요.

`플레이.cmd`로 실행한 뒤 **첫날 밤 · 세 번의 방문**을 선택하면 정상 배송 → 이웃 → 사칭 방문의 짧은 흐름을 경험할 수 있습니다. **자유 시연 · 생활과 문밖**은 기존의 검거까지 생존하는 전체 모드입니다.

- 이동 가감속, Shift 천천히 걷기, 보행음, 미세한 카메라 움직임을 추가했습니다. 시작 메뉴와 Esc 메뉴의 **시선 · 화면 설정**에서 감도·시야각·카메라 움직임을 조절합니다.
- 상호작용 거리를 2.2m로 줄이고 가림 검사를 추가했습니다. 가까이서 바라보는 사물의 이름만 표시합니다.
- 첨부 팔레트에 맞춰 실내와 가구를 차가운 콘크리트 색으로 정리했습니다. 인터폰에는 별도의 청색 계조·입자·주사선을, 렌즈에는 원형 마스크를 적용했습니다.

- 소리를 종류별로 분리해 노크·마찰음·발소리가 서로 끊기지 않게 했습니다. 실제로 멀어지는 발소리와 문 옆으로 옮겨가는 발소리의 위치가 다릅니다.

- 업무·수면·식사는 짧은 연출 후 진행합니다. Space/Esc로 건너뜁니다. 관찰·이동·메뉴는 생활 시간을 소비하지 않습니다.

상세 규칙·검증·남은 제작 범위는 [docs/UPGRADES.md](docs/UPGRADES.md)를 참고하세요.

## 바로 시연하기

기본 플레이는 **자유 시연 · 생활과 문밖**입니다. 원래 기획의 생활과 생존을 하나의 시간선에 연결한 모드입니다.

- PC에서 업무 시간을 정해 수입을 얻고, 침대에서 수면 시간을 정합니다. 초인종이 울리면 중단·재개를 선택합니다.
- 휴대폰에서 생필품·간편식·좋아하는 음식·조사 카메라·세 종류의 호신용품을 주문합니다. 모두 배송 후 회수가 필요합니다.
- 낮 배송과 수면 일정, 공복과 정신력을 함께 관리합니다. 오래 외출하지 않거나 잠이 부족해도 정신력이 줄어듭니다.
- 현관에서 주문·대화·소리·서로 다른 시야를 비교하고 문을 열지 판단합니다. 문 옆 사각지대에 사람이 남을 수 있습니다.
- 비축식은 접촉을 줄이고, 좋아하는 음식은 더 많은 정신력을 회복합니다. 미회수 물품은 3시간 뒤 사라집니다.
- 사용한 방어 수단은 다시 통하지 않습니다. 다른 수단이 필요하고 가격도 오릅니다.
- 문신·차량·설치 후 녹화를 수집해 경찰에 전달하면 검거가 앞당겨집니다. 기본 검거는 4일차 06시입니다.
- 관찰·실내 이동 중에는 시간이 흐르지 않습니다. 업무·수면·식사·대기·외출로 시간을 보냅니다. 현관의 3분 기다리기도 명시적인 대기 행동입니다.

처음에는 휴대폰에서 배송 시간을 확인하고 식량을 주문한 뒤, 업무와 수면을 조절하세요. 전체 항목과 구현 범위는 `docs/PLAN_COVERAGE.md`에 정리했습니다. 사적 제재·최종 대결은 원래 기획에서 미정이던 확장으로 남겨둡니다.

### 보조 메뉴: 현관 연출만 짧게 체험

현관 판단에 집중한 약 4–6분짜리 실시간 연출 테스트입니다. 세 건의 실제 배송과 두 번의 수상한 방문이 섞여 찾아옵니다. 생필품 두 묶음 이상을 확보하고 아침까지 버티면 성공합니다. 이 별도 목표는 본 게임의 생활·검거 목표를 대체하지 않습니다.

- `E` 현관 확인, 문 열기는 `E` 또는 버튼을 **1.2초간 유지**. 손을 떼면 취소
- 현관에서 `1` 인터폰 / `2` 렌즈 / `3` 귀 기울이기 / `4` 대화
- `Tab` 주문 내역 / `X` 물러나기 / `Esc` 일시정지 / `M` 음소거
- 확인 화면은 정지 화면이지만 방문자는 실시간으로 움직입니다. 다른 화면을 보거나 같은 화면을 다시 확인해야 변화를 볼 수 있습니다.
- 정상 물품도 너무 오래 두면 사라집니다. 계속 숨기만 하면 실패합니다. 재시작하면 순서가 바뀝니다.
- 소리 단서는 자막으로도 제공됩니다. 이어폰을 사용하면 방향을 더 쉽게 파악할 수 있습니다.

자세한 구현 범위는 `docs/DOOR_NIGHT.md`에 있습니다. 아래 생활 시스템과 기존 두 경로 시연도 메뉴에서 계속 선택할 수 있습니다.

시작 화면에서 **사망 시연** 또는 **생존 시연**을 선택합니다. **다음** 버튼으로 직접 진행하거나 **자동 시연**으로 5초마다 진행할 수 있습니다. Esc는 시연 일시정지입니다.

- 사망: 주문 없이 야근 → 수상한 방문 → 문 열기 → 사망 (4단계)
- 생존: 정상 배송 확인 → 문신·차량 관찰 → 경찰 제보 → 식사·수면·업무 → 검거 (14단계)

실제 게임 규칙으로 진행하며 엔딩이나 생존 수치를 강제로 설정하지 않습니다. 세부 순서는 `docs/DEMO.md`에 있습니다.

## 조작

- WASD: 이동 / 마우스: 시선
- E: 바라보는 사물과 상호작용 (약 2.2m 이내, 장애물에 가리지 않은 사물)
- Tab: 휴대폰 / J: 기록 / Esc: 메뉴·마우스 해제
- 시간은 행동으로만 흐릅니다. 관찰·이동·메뉴는 시간을 소비하지 않습니다.

## 기존 안내 시연의 시간표

1. 휴대폰(Tab)으로 간편식 주문. PC에서 2시간 업무 시작.
2. 19시 배송에 업무가 멈춥니다. 주문 번호 0417과 배달원의 말을 비교하고, 물품을 회수합니다.
3. 남은 업무를 계속하거나 중단합니다. 22시까지 일하거나 기다려봅니다.
4. 22시 수상한 방문은 인터폰·현관 렌즈로 비교합니다. 렌즈에서 증거를 기록합니다.
5. 문을 닫고 23시까지 기다립니다. 창밖에서 차량 증거를 기록합니다.
6. 휴대폰으로 증거를 신고합니다. 식사와 수면을 하며 2일차 18시까지 버팁니다.

| 방어 | 18,000원 스프레이는 1회 방어. 정신력 25 손실. 재사용 불가 |
| 산책 | 시간 1시간. 낮 정신력 18, 밤 5 회복(기본 감소 별도). 밤 정신력 35 미만 거부 |

## 의도적인 간소화

- 가구는 무료 Kenney CC0 에셋이며 관찰 화면의 인물은 코드로 만든 임시 저폴리 모델입니다. 방의 기본 구조·차량·인터폰·UI는 코드로 만든 그래픽입니다. 출처와 원본 라이선스는 `assets/CREDITS.md`에 있습니다.
- 인터폰/렌즈/창밖은 별도 3D 장면을 한 번 렌더링한 정지 화면이며, 시야에 따라 다른 단서를 보여줍니다. 통합 모드의 문신은 손목의 3D 표식으로 표시하며 초기 안내 시연은 텍스트 표식을 유지합니다.
- 초인종은 합성 오디오, 대화와 발소리는 텍스트입니다. 자유 이동 시간은 흐르지 않습니다.
- 산책은 선택과 결과로만 표현합니다. 긴 행동은 즉시 결과로 이동합니다.
- 초기 안내 시연의 스프레이는 즉시 지급됩니다. 통합 자유 시연에서는 모든 물품을 배송·회수해야 합니다.
- 통합 자유 시연은 간편식·좋아하는 음식·세 가지 방어 수단·조사 카메라·반복 노크를 포함합니다. 사적 제재와 최종 대결은 미정 확장입니다.
- 수동 저장 없이 한 세션으로 플레이합니다. 재시작하면 모든 상태가 초기화됩니다.

## 파일 구조

- `scripts/state.gd`: 시간·생활 수치·방문·증거·엔딩. UI와 독립된 게임 규칙
- `scripts/main.gd`: 3D 방·1인칭 이동·UI·초인종
- `scripts/furnished_room.gd`: 무료 GLB 가구 배치와 충돌
- `scripts/observation_3d.gd`: 임시 저폴리 인물이 등장하는 정지 관찰 화면과 화면별 필터
- `scripts/demo.gd`: 사망·생존 경로, 단계별 안내와 자동 시연
- `scripts/full_game.gd`: 생활 상태와 새 현관 관찰·공간음·길게 눌러 문 열기를 연결하는 통합 플레이
- `scripts/door_night_state.gd`: 랜덤 야간 방문·사각지대·물품 회수·생존 규칙
- `scripts/door_night.gd`: 실시간 현관 모드·전체 관찰 화면·길게 눌러 문 열기
- `scripts/night_audio.gd`: 형광등·노크·발소리·심장박동 등 절차적 오디오
- `assets/CREDITS.md`: 무료 그래픽 출처·라이선스·수정 내역
- `tests/test_state.gd`: 정상 생존과 실패 경로의 회귀 검증
- `docs/TEAM.md`: 팀별 작업 분담 제안
