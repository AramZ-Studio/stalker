# 스토커 — Godot MVP

Godot 4.6 · GDScript · 3D 1인칭 · 한국어. 무료 Kenney CC0 에셋을 동봉했으며 별도 에셋 구매나 플러그인 설치가 필요하지 않습니다.

## 실행

`플레이.cmd`를 더블클릭하거나 Godot 4.6에서 `project.godot`를 가져와 F6 대신 **F5**로 실행합니다.
현재 개발 PC에서는 `.tools/godot`의 공식 포터블 엔진을 사용합니다. 엔진 실행 파일과 생성 캐시는 GitHub에 올리지 않습니다. 저장소를 내려받은 팀원은 [Godot 4.6](https://godotengine.org/download/archive/4.6-stable/)을 설치하거나 포터블 버전을 받은 뒤 `project.godot`를 열고 **F5**로 실행하세요.

## 팀 작업 시작

```powershell
git clone https://github.com/phj3137/stalker.git
cd stalker
git switch -c feature/작업이름
```

Godot 4.6에서 프로젝트를 열고 수정한 뒤 작업 브랜치를 push하고 Pull Request를 만듭니다. 직접 브랜치를 push할 팀원은 저장소 관리자가 **Settings → Collaborators**에서 초대해야 합니다. 공개 저장소를 읽거나 복제하는 데는 초대가 필요하지 않습니다.

에셋은 `assets/`에 포함되어 있습니다. `.godot/`, `.tools/`, 개인 설정·비밀값은 커밋하지 마세요. 팀원 간 같은 Godot 버전을 사용합니다. 역할과 작업 시작점은 `docs/TEAM.md`, 시연 순서는 `docs/DEMO.md`를 참고하세요.

## 바로 시연하기

시작 화면에서 **사망 시연** 또는 **생존 시연**을 선택합니다. **다음** 버튼으로 직접 진행하거나 **자동 시연**으로 5초마다 진행할 수 있습니다. Esc는 시연 일시정지입니다.

- 사망: 주문 없이 야근 → 수상한 방문 → 문 열기 → 사망 (4단계)
- 생존: 정상 배송 확인 → 문신·차량 관찰 → 경찰 제보 → 식사·수면·업무 → 검거 (14단계)

실제 게임 규칙으로 진행하며 엔딩이나 생존 수치를 강제로 설정하지 않습니다. 세부 순서는 `docs/DEMO.md`에 있습니다.

## 조작

- WASD: 이동 / 마우스: 시선
- E: 바라보는 사물과 상호작용 (약 2.7m 이내)
- Tab: 휴대폰 / J: 기록 / Esc: 메뉴·마우스 해제
- 시간은 행동으로만 흐릅니다. 관찰·이동·메뉴는 시간을 소비하지 않습니다.

## 첫 플레이 안내 (약 10~20분)

1. 휴대폰(Tab)으로 간편식 주문. PC에서 2시간 업무 시작.
2. 19시 배송에 업무가 멈춥니다. 주문 번호 0417과 배달원의 말을 비교하고, 물품을 회수합니다.
3. 남은 업무를 계속하거나 중단합니다. 22시까지 일하거나 기다려봅니다.
4. 22시 수상한 방문은 인터폰·현관 렌즈로 비교합니다. 렌즈에서 증거를 기록합니다.
5. 문을 닫고 23시까지 기다립니다. 창밖에서 차량 증거를 기록합니다.
6. 휴대폰으로 증거를 신고합니다. 식사와 수면을 하며 2일차 18시까지 버팁니다.

## 의도적인 간소화

- 가구와 인물은 무료 Kenney CC0 에셋입니다. 방의 기본 구조·차량·인터폰·UI는 코드로 만든 그래픽입니다. 출처와 원본 라이선스는 `assets/CREDITS.md`에 있습니다.
- 인터폰/렌즈/창밖은 별도 3D 장면을 한 번 렌더링한 정지 화면이며, 시야에 따라 다른 단서를 보여줍니다. 문신은 현재 텍스트 표식으로 표시합니다.
- 초인종은 합성 오디오, 대화와 발소리는 텍스트입니다. 자유 이동 시간은 흐르지 않습니다.
- 산책은 선택과 결과로만 표현합니다. 긴 행동은 즉시 결과로 이동합니다.
- 스프레이는 배송을 기다리는 대신 구매 즉시 지급됩니다.
- 현재는 간편식만 제공하며, 수면 방해 반복 호출·사적 제재·추가 호신용품·음식 종류·랜덤 사건은 미구현입니다.
- 수동 저장 없이 한 세션으로 플레이합니다. 재시작하면 모든 상태가 초기화됩니다.

## 파일 구조

- `scripts/state.gd`: 시간·생활 수치·방문·증거·엔딩. UI와 독립된 게임 규칙
- `scripts/main.gd`: 3D 방·1인칭 이동·UI·초인종
- `scripts/furnished_room.gd`: 무료 GLB 가구 배치와 충돌
- `scripts/observation_3d.gd`: 무료 인물 모델이 등장하는 정지 관찰 화면
- `scripts/demo.gd`: 사망·생존 경로, 단계별 안내와 자동 시연
- `assets/CREDITS.md`: 무료 그래픽 출처·라이선스·수정 내역
- `tests/test_state.gd`: 정상 생존과 실패 경로의 회귀 검증
- `docs/TEAM.md`: 팀별 작업 분담 제안
